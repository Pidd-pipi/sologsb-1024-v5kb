# 光影谱 · 灯光演出提示设计台

面向灯光设计、编程与舞台监督的演出提示工作台。按场次维护通道、灯位、颜色、亮度、渐变、跟随关系和备注，并在拖动顺序后自动重算时间、提示通道或逻辑冲突。

## 功能

- 多方案数据模型；每个方案包含多个场次，每个场次包含完整灯光提示。
- 按场次维护灯位、控制通道、颜色、色值、亮度、渐入、保持、渐出、跟随目标、触发动作、备注和执行状态。
- 使用鼠标或键盘拖动提示排序；每次排序、参数应用或删除后自动重算全剧时间。
- 自动检测同通道叠光、跟随目标不存在或顺序异常、缺失通道/灯位、亮度越界、灯位重复等问题。
- 多个方案并排比较，按场次顺序显示提示时间、通道和亮度。
- 可冻结已确认场次；冻结后提示参数与排序只读，舞台监督或灯光设计可解除冻结。
- 未完成提示快捷跳转；`Alt+N` 可在所有未确认或存在阻断冲突的提示间循环移动。
- 角色权限：灯光设计可完整编辑，编程执行可调整参数，舞台监督可冻结场次，只读角色只能查看。
- **执行对账（GO 记录核对）**：
  - 导入断网控台带回的 GO 记录 JSON，按稳定编号（场次 + 提示编号）与计划配对。
  - 重复导入同一条记录只合并一次（记录内容指纹去重）；同一提示出现两份不同记录时并列保留，等待舞台监督确认。
  - 确认前绝不改动全剧时间；差异同时展示 GO 时刻提前/延后与亮度、渐变、通道等参数变化。
  - 提示的编号、顺序或渐变时长一旦变化，未确认记录立即标记“已失效待重算”；已确认记录保留其当时的计划快照，不受后续改动影响，确认后补入的新记录会重新进入待确认队列。
  - 冻结场次禁止写入对账；编程执行只能补充 GO 记录，确认/废弃只能由舞台监督完成，重算可由灯光设计或舞台监督执行。
  - 合并失败（JSON 无法解析或整批被拒绝）时原方案与待处理清单完全不变。
  - 导出 JSON 同步带上执行记录、每条记录的差异、确认状态与确认时快照。
- 离线草稿自动写入 `localStorage`，模拟保存接口展示在线/离线同步状态。
- 最多 50 步撤销重做；快捷键包括 `↑/↓` 选择提示、`F` 冻结/解冻、`Ctrl/⌘+Z` 撤销、`Ctrl/⌘+Shift+Z` 重做、`Ctrl/⌘+S` 保存。
- 时间轴、提示列表、复选关系图和冲突面板均提供语义标签、焦点样式和读屏描述。
- 导出当前方案 JSON，便于制作交接与外部备份。

## 技术栈

- React + TypeScript
- Vite
- Chakra UI
- dnd-kit（鼠标与键盘排序）
- localStorage
- 无后端服务，全部数据在浏览器本地处理

## 本地开发

```bash
npm install
npm run dev
```

打开终端显示的 Vite 地址。源码没有硬编码宿主端口。

## 生产构建

```bash
npm install
npm run build
```

生产产物生成到 `dist/`。可用 `npm run preview` 预览。

## Docker

```bash
docker build -t sologsb-1024 .
docker run --rm -p 10024:80 sologsb-1024
```

容器内 nginx 监听 `80`，根据根端口表映射到宿主 `10024`。

## 数据说明

方案、提示、冻结状态、角色选择、草稿和执行对账都保存在当前浏览器。清除站点数据会删除本地设计稿，重要方案请导出 JSON 备份。

## GO 记录文件格式

断网控台导出的 JSON 可以是记录数组，或带 `source` 标题的对象；字段除 `cue`/`cueNumber` 与 GO 时刻外均可省略：

```json
{
  "source": "断网控台 · 首场 GO 记录",
  "records": [
    { "scene": "序章 · 入梦", "cue": "Q2", "firedAt": 21, "note": "月幕提前 3 秒" },
    { "scene": "独白 · 失语", "cue": "Q10", "firedAt": 120, "brightness": 52, "fadeIn": 9, "fadeOut": 12 }
  ]
}
```

- `scene`（场次名）或 `sceneOrder`（场次顺序）用于定位场次；两者都省略时在全方案按提示编号查找。
- `firedAt` 为 GO 时刻（相对演出开始的秒），也可用 `timeOffset`。
- 记录身份只由内容指纹决定：同一条记录重复导入只合并一次；同一编号下内容不同的多份记录会并列保留。
- 可使用界面中的“示例：首场 GO / 次场 GO”按钮体验提前 GO、改参、重复导入、冻结场次拒绝与编号缺失等场景。
